Fitur

Semua yang kamu butuhkan
saat makan bareng.

🤖
Scan Struk dengan AI
Model CRNN + OpenVINO membaca teks nota secara offline. GPT-4o membantu parsing item, harga, pajak, dan service charge secara otomatis — tidak perlu ketik manual sama sekali.
🔄
Sinkronisasi Real-time
Semua perubahan (pilihan menu, pengeluaran manual, edit tagihan) tersinkronisasi ke semua perangkat via WebSocket.
🧾
Multi-nota
Scan beberapa nota sekaligus dalam satu sesi. Cocok untuk meja besar dengan banyak bill.
✏️
Edit Manual
Tambah pengeluaran manual (parkir, bensin, dll) dan edit tagihan akhir per orang sesuai kesepakatan.
📊
Deteksi Pajak Otomatis
Sistem mendeteksi skema pajak dan service charge dari nota dan menghitungnya secara proporsional.
📱
Android & iOS
Satu sesi, dua platform. Host bisa pakai Android, teman bisa pakai iPhone, semuanya sinkron.
Teknologi

Dibangun dengan
teknologi terkini.

Kombinasi deep learning, LLM komersial, dan framework modern untuk pengalaman terbaik.

OCR
CRNN + OpenVINO
Convolutional Recurrent Neural Network dioptimalkan dengan Intel OpenVINO untuk inferensi 2.7× lebih cepat.
LLM
GPT-4o Vision
Parsing teks OCR dan fallback vision untuk nota berkualitas rendah. Mendeteksi item, harga, pajak, dan diskon.
Backend
FastAPI + Redis
REST API asinkronus dengan WebSocket real-time. Redis (Upstash) untuk sinkronisasi state multi-worker.
Mobile
Flutter
Satu codebase untuk Android dan iOS. State management dengan Provider, animasi 60 FPS.
Deploy
Hugging Face Spaces
Backend di-deploy sebagai Docker container di Hugging Face Spaces. Gratis, reliable, dan mudah di-update.
Data
CORD v2 Dataset
1.000 gambar nota restoran dengan anotasi bounding box. Akurasi kata 91.3%, akurasi karakter 95.7%.

FAQ

Pertanyaan umum.

Apakah aplikasi ini gratis?
Ya, Bagi Tagihan sepenuhnya gratis untuk digunakan. Tidak ada biaya berlangganan atau pembelian dalam aplikasi.
Apakah perlu internet untuk scan nota?
Ya, aplikasi memerlukan koneksi internet untuk mengirim gambar ke server AI dan melakukan sinkronisasi antar perangkat.
Berapa orang maksimal dalam satu sesi?
Tidak ada batas maksimal peserta. Semua perangkat akan tersinkronisasi secara real-time selama dalam satu sesi.
Apakah data nota saya disimpan?
Foto nota diproses sementara di server dan tidak disimpan secara permanen. Data sesi otomatis terhapus setelah 6 jam.
Apakah tersedia untuk iPhone?
Saat ini APK tersedia untuk Android. Versi iOS sedang dalam proses distribusi. Teman dengan iPhone tetap bisa bergabung sesi yang dibuat dari Android.
